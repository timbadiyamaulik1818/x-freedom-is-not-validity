# X-Freedom Is Not Validity

**Certification-gated gate-level switching activity for pre-silicon power analysis**

Removing unknown (`x`) values from a gate-level simulation does not make its
switching activity valid. This repository contains the article, the full
experimental harness, and every result it reports. Nothing here needs a
commercial licence.

## The result in one table

On a synthesized 32-bit pipelined processor with 680 sequential elements
(646 of them without reset):

| Gate-level initialization | Reproduces RTL execution | Unknown transitions | Signal power error |
|---|---|---|---|
| none | no — diverges at cycle 2 | 67.3% | −99.4% |
| independent random (what register-init options do) | **0 of 20 seeds** | **0.0%** | −88.6% |
| one vector shared with RTL, certified per cycle | **20 of 20 seeds** | 0.0% | reference |

The middle row is the point: every unknown value is gone, a check for `x`
passes, and the netlist is executing a different program. It halts after 5
cycles where RTL runs 107, and its peak-power cycle is 0 instead of 70.

The method studied here applies **one** power-up state vector to both the RTL
and the gate-level model through a synthesis-derived correspondence map, runs
both, compares all mapped state every cycle with a **four-state** comparison,
and releases activity to power analysis **only for cycles where that
comparison held**.

## Quick start

```sh
brew install icarus-verilog yosys      # macOS
# sudo apt install iverilog yosys      # Debian / Ubuntu

./RUN_ALL.sh quick                     # headline result, ~5 s
./RUN_ALL.sh                           # every experiment, a few minutes
```

`quick` runs a self-contained two-file testcase covering all arms in one
simulation. The same two files ran unchanged on Synopsys VCS X-2025.06-SP1 and
Siemens QuestaSim 2025.2 and produced output identical to Icarus Verilog 13.0 —
logs in `results/simulator_runs/`.

## Limitations

The designs are small models, not production silicon. The cell library and
energy values are synthetic, so power magnitudes are illustrative and only the
relative differences between arms carry meaning. No delay annotation was used.
Activity, power and timing come from Icarus Verilog; the three-simulator
agreement covers the equivalence results of the 58-element testcase. At this
design size the method's run-time cost was below timing noise, which says
nothing about per-cycle cost on long workloads. See the article's *Threats to
Validity* section.
